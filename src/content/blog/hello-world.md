Welcome to my new blog! I've wanted a place to write things down for a long
time, and I finally set one up.

## What to expect

Mostly notes on software I'm building, things I'm learning, and the occasional
opinion. I'll try to keep posts short and practical.

> Writing is thinking. To write well is to think clearly.
> — David McCullough

## How this site works

Every post is a Markdown file in `src/content/blog/`. Pushing to `main` builds
the site with [Astro](https://astro.build) and deploys it automatically.

Thanks for reading — you can subscribe via [RSS](../../rss.xml) if you'd like
to follow along.
