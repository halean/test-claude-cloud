title: Using MDX for interactive posts
description: MDX lets you drop components straight into your Markdown. Here's a tiny example.
pubDate: 2026-09-10

---

export const Callout = ({ children }) => (
  <aside style={{
    padding: '1rem 1.25rem',
    borderRadius: '10px',
    background: 'var(--accent-soft)',
    borderLeft: '3px solid var(--accent)',
    fontFamily: 'var(--font-sans)',
    fontSize: '1rem',
  }}>
    {children}
  </aside>
);

Posts ending in `.mdx` can use components alongside regular Markdown.

<Callout>💡 This callout is a component defined right inside the post.</Callout>

You can also import components from `src/components/` and reuse them across
posts. This is handy for embeds, charts, or anything else Markdown can't
express on its own.
